数据同步设置

使用说明：免登录共享模式无需注册任何账号或令牌。所有设备填写同一个「共享库 ID」即可互相看到抄表与签字数据（留空使用内置演示库，可直接体验）；也可自定义 6–60 位字母 / 数字 / 连字符 ID，建立独立的数据空间。注意：该模式数据公开可读写，适合演示与日常协作，请勿存放敏感信息。
使用说明：云同步模式下，每条抄表记录存为一个 GitHub Issue，公开读取、令牌写入，跨设备/跨用户可共享数据。若仓库尚未开通 Issues，可在 GitHub 上新建仓库 GCNAAT/meter-records 并勾选「Add a README」即可。未配置令牌或网络不可达时，系统自动降级为本地存储，不影响使用。
